一、地图编辑器目录结构
编辑器相关代码，放在Editor/MapEditor文件夹中
运行时代码放在GameMain/中新建目录存放
二、地图中节点
Scene
DataRoot
Building
Decorate
Resource

相关配置表：
MapBuildingCfg
MapDecorateCfg
MapResourceCfg
AssetPathCfg -- 资源路径表

导出收据，客户端导出为scriptObject，服务端导出为二进制文件
Building、Decorate、Resource各自导出自身文件，导出文件命名为 模块名+Data，例如BuildingData

支持两种模式，grid移动和自由移动，grid移动时，设置格子大小，并做移动吸附辅助

导出数据大概结构：
int id 对应配置表中的id
vector2 pos 世界坐标
vector2 size 大小，可以取collider的大小
float rotationY 绕Y的旋转

这里不需要生成一个唯一id, 如果需要其他补充，添加就可以了

导出数据放在Assets/BundleRes/MapData中，新建当前场景文件夹

当打开Main场景，WorldChunkStreaming初始化地块后，用四叉树将上面导出的数据进行管理
这些数据会根据player位置进行创建、销毁对应的gameobject
