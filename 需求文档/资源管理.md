# 目标：自动化组织资源

## 1. 使用的插件描述

本工程资源管理使用了Unity官方的Addressable
分组使用了Unity Addressable Importer，文档在
E:\Work\GameFramework\Client\Library\PackageCache\com.littlebigfun.addressable-importer@f15c79e9d1\Documentation~

### 1.1 GroupTemplate: 打包模板

1. 单独文件打包成Bundle: Assets/AddressableAssetsData/AssetGroupTemplates/PackSeparately.asset
2. 所有文件一起打包成Bundle: Assets/AddressableAssetsData/AssetGroupTemplates/PackTogether.asset

### 1.2 定义模板类型 packType

1. 单独文件打包成Bundle
2. 所有文件一起打包成Bundle

### 1.3 定义group 和对应的匹配类型

1. Font -matchType: .\*
2. Material -matchType: .mat
3. Shader -matchType: .shader
4. Texture -matchType: png|jpg
5. Mesh -matchType: .asset
6. Animation -matchType: .ani
7. Prefab -matchType: .prefab
8. UI -matchType: .prefab
9. UISprite -matchType: .png|.jpg|.spriteatlas(v2|)
10. FX -matchType: .prefab
11. MapData -matchType: .asset
12. MapChunk -matchType: .prefab
13. Scene -matchType: .unity
14. GlobalData -matchType: .\*
15. SkyBox -matchType: .\*
